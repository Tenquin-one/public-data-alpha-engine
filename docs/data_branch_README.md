# Public Data Alpha Engine — time-axis assets

This orphan branch stores immutable time-axis bundles generated by GitHub Actions.

- Existing Seoul layout:
  - `bundles/YYYY/MM/DD/<run-id>.tar`
  - `runs/YYYY/MM/DD/<run-id>.json`
  - `state/latest_hashes.json`
- Airport Friction namespace:
  - `bundles/airport_friction/YYYY/MM/DD/<run-id>.tar`
  - `runs/airport_friction/YYYY/MM/DD/<run-id>.json`
  - `state/airport_friction/latest_hashes.json`

Each tar stores its immutable run manifest plus only newly observed gzip payloads. Every run JSON remains even when every payload is a duplicate or a source failed. The source code and documentation live on `main`. Every endpoint/query is redacted and no API key is stored here.
