# Public Data Alpha Engine — time-axis assets

This orphan branch stores immutable Seoul realtime collection bundles generated by GitHub Actions.

- `bundles/YYYY/MM/DD/<run-id>.tar`: manifest plus new gzip payloads
- `runs/YYYY/MM/DD/<run-id>.json`: every run, including duplicates and failures
- `state/latest_hashes.json`: compact deduplication state

The source code and documentation live on `main`. Every endpoint is redacted and no API key is stored here.
